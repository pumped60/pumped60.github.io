# GH Assistant

**Open it: https://pumped60.github.io/GH-Assistant/**

Reads medication bottle labels into a one-line summary and organizes provider lists by specialty, with copy-ready intake summaries. It runs in the browser with no login. On a phone, use Share → Add to Home Screen to get an app icon.

This repo holds only the built page, in the `GH-Assistant` folder; the site root forwards there, and so does any spelling of `/gh-assistant` (through `404.html`). It is published by GitHub Pages; the source code lives in pumped60/GH-Assistant (`npm run build` writes these files to `dist/site/`).
